## Overview

This project practices Python file handling, JSON serialization,
deserialization, and simple object representation.

## Main Files

| File | Purpose |
| --- | --- |
| `0-read_file.py` | Print the contents of a UTF-8 text file |
| `1-write_file.py` | Write a string to a UTF-8 text file |
| `2-append_write.py` | Append a string to a UTF-8 text file |
| `3-to_json_string.py` | Convert a Python object to a JSON string |
| `4-from_json_string.py` | Convert a JSON string to a Python object |
| `5-save_to_json_file.py` | Save a Python object to a JSON file |
| `6-load_from_json_file.py` | Load a Python object from a JSON file |
| `7-add_item.py` | Store command-line arguments in `add_item.json` |
| `8-class_to_json.py` | Return the dictionary form of an object |
| `9-student.py` | Student class with `to_json()` |
| `10-student.py` | Student class with filtered `to_json(attrs)` |
| `11-student.py` | Student class with `reload_from_json()` |
| `12-pascal_triangle.py` | Build Pascal's triangle |

## Additional Files

| File | Purpose |
| --- | --- |
| `100-append_after.py` | Insert text after matching lines in a file |
| `101-stats.py` | Parse log input and print metrics |
| `read_write_heap.py` | Replace a string in the heap of a running process |
| `tests/` | Example checker files and local test drivers |

## Notes

- All Python files start with `#!/usr/bin/python3`.
- All Python files are expected to follow `pycodestyle`.
- The project uses built-in file operations and JSON handling.
