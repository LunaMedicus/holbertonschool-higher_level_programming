# Python Serialization

Short exercises on saving and loading data in Python.

## Files

- `task_00_basic_serialization.py`: JSON save/load for dictionaries
- `task_01_pickle.py`: pickle support for a custom class
- `task_02_csv.py`: convert CSV data to JSON
- `task_03_xml.py`: serialize and deserialize dictionaries with XML
- `task_04_net.py`: send serialized dictionaries over sockets
